# EXEL Real Estate AI Skills OS

This package defines a governed AI workflow layer for EXEL real-estate sales operations.

## Goal

Create reusable Claude Code skill specifications for:

1. Conversation to CRM and follow-up
2. Raw material to client-ready pack
3. Approved answer composition
4. Asset extraction and canonization
5. CRM hygiene auditing
6. EXEL SalesFlow Room product documentation

## Operating principle

AI may structure, draft, assemble, extract, audit, and recommend.

Humans must approve sensitive commercial, financial, legal, contractual, or customer-facing outputs.
