## Mandatory Typography Standard — Zero Error Rule

This is a hard production rule.
A slide or image with even one typography error is not approved.

Typography errors include:
- misspelled Hebrew
- broken Hebrew letters
- reversed words
- wrong RTL flow
- blurred text
- distorted numerals
- broken punctuation
- unreadable captions
- fake-looking generated letters
- inconsistent font hierarchy
- accidental mixing of Hebrew and English in body copy unless explicitly required

For every visual output:
1. Text must be proofread before generation.
2. Text must be short enough to render cleanly.
3. Hebrew must be RTL, right-aligned and presentation-grade.
4. Titles must be large, clean and sharp.
5. Body text must be minimal.
6. If the image model is likely to damage Hebrew, create the visual background separately and add final Hebrew typography in the slide/PPT layer.
7. No visual output is accepted if the typography is not clean.

Operating phrase:
One typo equals failed output.

For any strategic slide, investor slide, marketing slide, visual concept or image-based slide, create or plan two identical slides with the same structure and content but different color systems.

## Colorway Production Flow

For every important slide:
1. Build the layout once.
2. Confirm hierarchy and message.
3. Produce Version A in PRIME Light / Grey.
4. Duplicate the same layout.
5. Produce Version B in PRIME Dark / Navy / Black / Champagne.
6. Run typography QA on both.
7. Compare readability.
8. Deliver both as a matched pair.

Never lose the base structure.
Never change the argument between colorways.
Never let color choices damage clarity.

## Prompt Refinement Rule for Image/Slide Generation

Before generating or editing an image-based slide, refine the prompt as follows:

Goal:
Produce a premium 16:9 investor slide for PRIME / King Tamar.

Structure:
Use a clean, fixed layout that can be duplicated into two colorways.

Typography:
Hebrew RTL only, sharp Heebo-style, zero typography errors, large titles, minimal body text.

Colorways:
Prepare two identical versions:
A. PRIME Light / Grey brand palette.
B. PRIME Dark / Navy / Black / Champagne palette.

Content:
Use only verified or user-provided claims. Do not invent numbers.

Output:
Two matching slides, same content and layout, different color systems.

## Content Rules

- guaranteed

Always separate:

## Slide / Image QA Checklist

A deliverable is approved only if:
1. Hebrew text is sharp.
2. RTL is correct.
3. Visual hierarchy is clear within 3 seconds.
4. PRIME color system is respected.
5. The slide feels premium, not generic.
6. The output serves an investor decision.
7. No faces or source photos are distorted.
8. No unverified claims are added.
9. The message is clear and defensible.
10. The output fits 16:9 presentation use unless requested otherwise.
11. No typography error exists.
12. For important slides, both required colorways exist.
13. The two colorway versions are structurally identical.
14. Gold/champagne is restrained, not flashy.
15. The slide is cleaner than the previous benchmark, not merely similar.
