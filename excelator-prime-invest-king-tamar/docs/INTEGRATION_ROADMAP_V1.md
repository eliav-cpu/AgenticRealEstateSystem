# Integration Roadmap V1

Artifact: EXCELDOR_INTEGRATION_ROADMAP_V1.xlsx

This document summarizes the safe integration plan for the Excelator King Tamar system.

## Integration order

1. Data foundation: parking, finish packages, marketers, proposal log.
2. Settings foundation: settings center and project master.
3. Investment engines: LTR, STR, value appreciation, flip.
4. Media architecture: media index and floor plan index.
5. Internal command center.
6. Premium client proposal.
7. Online status layer for sales status only.

## Protected zones

- ENGINE
- PAYMENT_MODEL
- SIMULATOR core cells
- CLIENT_PROPOSAL calculation cells
- QA
- QA_MATRIX
- DATA_UNITS until mapped

## QA gates

- selected unit exists
- combined payments equal total deal price
- display percentages equal 100 percent
- shell payments close to adjusted shell price
- finish payments close to full finish price
- parking payments close to adjusted parking price
- no internal margin visible to client
- no formula errors in active sheets
