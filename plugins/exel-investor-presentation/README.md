# EXEL Investor Presentation

## Purpose
Build investor-grade real-estate presentations that move the client from understanding the opportunity to reviewing the numbers and making a disciplined decision.

## Responsibilities
- Deck narrative architecture
- Slide copy and hierarchy
- Visual QA and refinement direction
- Meeting-room readability
- Project story and trust layer
- Transition from presentation to simulator
- Internal presenter guidance separation

## Source Priority
1. Approved client-facing copy
2. Source-log and project documents
3. Sales playbook for internal talk tracks only
4. Visual brand system
5. Financial model and simulator outputs
6. Project images and verified data

## Output Rules
- Keep screen copy short, premium, Hebrew-first, and clear within 3 seconds.
- Keep internal sales guidance separate from client-facing slides.
- Do not invent project data or financial claims.
- Preserve RTL, clean hierarchy, and EXEL design discipline.

## Core Workflows
- build-deck-outline
- rewrite-slide
- visual-qa
- create-presenter-notes
- prepare-investor-meeting-flow
- transition-to-simulator
