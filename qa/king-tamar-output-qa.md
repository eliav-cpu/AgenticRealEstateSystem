# King Tamar Output QA

Run this checklist before delivering any PRIME / King Tamar output.

## 1. Source Layer
- [ ] Is this Client Copy or Sales Playbook?
- [ ] If screen copy: based only on Client Copy V6.
- [ ] If speech/internal guide: based only on Sales Playbook V6.
- [ ] No mixing between slide copy and internal guidance.

## 2. Hebrew / RTL / Typography
- [ ] Hebrew is RTL.
- [ ] Hebrew is right-aligned.
- [ ] Heebo-style hierarchy.
- [ ] No typos.
- [ ] No broken Hebrew.
- [ ] No smeared or fake text.
- [ ] Title readable from meeting-room distance.

## 3. Slide Logic
- [ ] The slide is clear within 3 seconds.
- [ ] It has a strong headline.
- [ ] It has a short subtitle.
- [ ] It has 3–4 concise cards maximum.
- [ ] It advances the client toward simulator, unit selection or reservation.

## 4. Commercial Safety
- [ ] No guaranteed return language.
- [ ] No certain appreciation language.
- [ ] No risk-free claims.
- [ ] No invented numbers.
- [ ] Numeric/financial/regulatory/commercial claims have a source or are marked `דורש אימות`.

## 5. Visual DNA
- [ ] PRIME colors only.
- [ ] No loud blue.
- [ ] Champagne is subtle.
- [ ] No generic Canva style.
- [ ] Cards feel like premium decision units.
- [ ] Light and Dark variants keep identical structure when required.

## 6. Final Delivery
- [ ] Output is immediately usable.
- [ ] User does not need to decode the next step.
- [ ] If a choice is needed, give only the next necessary choice.
