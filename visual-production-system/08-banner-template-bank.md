# 08 - Banner Template Bank

## Purpose
This file defines reusable banner structures for PRIME / King Tamar and related real-estate campaigns.

Use this bank for:
- Facebook ads
- Instagram feed
- Instagram stories
- remarketing banners
- lead generation creatives
- webinar creatives
- WhatsApp campaign visuals

## Core Banner Rule
A banner is not a mini presentation.
A banner must sell one clear action.

## Universal Banner Structure

```text
1. Main hook
2. Value line
3. 2-3 proof / benefit points
4. Logo / trust seal
5. CTA
```

## Mobile Readability Rule
If the banner is not readable on a phone in 2 seconds, it fails.

## Template 1 - Income Hook Banner

### Best For
Lead generation campaigns focused on expected income.

### Structure
```text
Main headline:
כ-60,000 ש״ח בשנה

Supporting line:
הכנסה צפויה מנכס פרימיום בטביליסי, בירת גאורגיה

Value points:
- החל מהון עצמי של כ-100,000 ש״ח
- אפשרות למימון בנקאי בערבות בנקאית
- בדיקת התאמה אישית לפני החלטה

CTA:
בדוק התאמה להשקעה
```

### Visual Direction
- dominant headline across top area
- project image lower or left-side
- text block right aligned
- logo bottom
- seal under logo, diagonal and controlled
- clean premium background

### QA Notes
- Mark all financial figures as requiring verification before public use.
- Use צפי, not guarantee language.

## Banner Copy Rules

### Allowed Language
Use:
- צפי
- פוטנציאל
- בדיקה אישית
- סימולציה
- תהליך מסודר
- בחירת יחידה
- התאמה למשקיע
- לפי חומרי הפרויקט

### Avoid
Do not use:
- מובטח
- ודאי
- ללא סיכון
- תשואה מובטחת
- עליית ערך ודאית
- השקעה בטוחה as a factual guarantee

If using the phrase השקעה בטוחה as a brand-style seal, it must be treated as a brand motif, not a legal or financial guarantee.

## Prompt For Generating Banner Visual Without Final Text

```text
Create a premium 4:5 vertical real-estate investment banner layout for Israeli investors. Private banking meets premium real estate. Use a clean PRIME visual system with large empty headline zone at the top, project image in the lower section, right-aligned empty text zones, small logo area at the bottom, subtle diagonal seal area under the logo, and clear CTA button zone. Use PRIME Navy #0F1E3A, White #FFFFFF, Mist Gray #F3F4F6, Deep Blue #2F63C8 and subtle Champagne Sand #D6C7A1. Do not include final Hebrew text. No fake letters. No generic Canva look. Leave all text areas clean for live Hebrew typography in Canva.
```

## Prompt For Correcting Existing Banner

```text
Preserve the exact existing banner concept, colors, image direction and composition. Do not redesign. Improve only the requested text hierarchy, font sizes, RTL alignment, logo placement, seal placement and CTA clarity. Make the main headline the dominant element. Keep Hebrew sharp, clean, right-aligned and readable on mobile. Produce a full version and a clean version with the same design but without final text.
```

## Final Banner QA

Before release:
- main hook is dominant
- no more than 3 supporting points
- CTA is visible
- mobile readable
- Hebrew is clean
- no risky absolute claims
- financial claims are verified or marked
- logo is controlled
- seal is elegant
- clean version exists
