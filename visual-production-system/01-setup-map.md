# 01 - Setup Map

## Goal
Create a practical operating layer for improving:
- presentation slides
- image prompts
- banners
- social ads
- Hebrew RTL assets
- clean visual templates

## Recommended Tool Roles

### GitHub
GitHub is the operating brain.

Use it for:
- DNA documents
- prompt banks
- QA checklists
- approved language
- reusable workflow files
- agent instructions
- source-control for every important update

### ChatGPT / GPT Image
Use for:
- visual concept creation
- image variations
- background generation
- mockups
- fast creative exploration

Important rule:
Do not rely on generated Hebrew typography inside images.
Use GPT Image mainly for layout, atmosphere, composition, backgrounds and visual direction.

### Canva
Use for:
- final Hebrew typography
- banners
- social ads
- brand templates
- resizing formats
- editable campaign assets
- client-facing static visuals

### Figma
Use for:
- design system
- slide masters
- exact visual systems
- components
- layout control
- reusable frames
- high-end visual QA

### Google Drive
Use for:
- source decks
- project files
- client documents
- price lists
- internal knowledge
- final export archive

## Minimum Viable Stack
Start with this small stack:

```text
GitHub + ChatGPT + Canva + Figma + Google Drive
```

Avoid adding too many external tools before the core line is stable.

## Production Levels

### Level 1 - Fast Creative
Use for quick examples and idea testing.

Output:
- 1-3 visual directions
- short prompt
- no complex source logic

### Level 2 - Client-Ready Asset
Use for real banners, slides and meeting materials.

Output:
- source basis
- exact copy
- layout direction
- visual prompt
- Hebrew RTL QA
- final clean version

### Level 3 - Reusable System
Use for assets that will repeat across campaigns.

Output:
- template
- approved copy bank
- prompt bank
- QA checklist
- Canva/Figma handoff instruction

## Default Rule For Existing Designs
When the user asks to improve an existing banner or slide:

```text
Preserve the existing design direction.
Change only what was requested.
Improve clarity, hierarchy and sharpness without rebuilding from zero.
```

## Default Rule For New Designs
When the user asks to create a new visual:

```text
Create 2 visual directions: Light and Dark.
Keep the same message and structure across both.
```

## Default Rule For Hebrew
Hebrew must be:
- right-aligned
- RTL
- readable
- sharp
- short
- client-safe
- without fake AI letters

If the model cannot produce clean Hebrew, generate the asset without final text and add text later in Canva/Figma.
