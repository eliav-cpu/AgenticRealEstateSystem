## Required workflow

### 1. Source extraction

Read all uploaded materials and separate the information into:

- verified facts
- project materials
- working assumptions
- marketing claims
- missing data
- client-ready copy
- sensitive claims that require review

For every important fact, include the source name or source context.

### 2. Project thesis

Build a project thesis using this structure:

- what the project is
- where it sits
- why the location matters
- who stands behind it
- what the product offers
- why the timing may matter
- how the investor should examine it
- what remains to verify

### 3. Audience mapping

Define the audience:

- primary investor profile
- emotional need
- rational need
- main fears
- main objections
- decision triggers
- likely questions

### 4. Narrative structure

Build the presentation as a decision journey:

1. big story
2. trust
3. market logic
4. location
5. product
6. benchmark
7. numbers
8. investor fit
9. process
10. next action

For King Tamar, use the locked story flow:

City -> tourism -> urban development -> address -> King David benchmark -> product -> numbers -> trust -> action

### 5. Slide outline

For every slide, provide:

- slide title
- psychological goal
- screen copy
- speaker note
- visual direction
- source status
- risk note if needed

### 6. Approved copy extraction

Create reusable copy blocks:

- hero lines
- trust lines
- location lines
- project lines
- process lines
- CTA lines
- risk-aware lines
- FAQ answers

### 7. Risk language review

Flag and replace words such as:

- guaranteed
- no risk
- safe money
- certain return
- absolute demand
- immune
- bulletproof
- full peace of mind

Use instead:

- potential
- thesis
- benchmark
- source-based
- should be reviewed
- structured evaluation
- investor fit
- according to project materials
- subject to review

### 8. Output formats

Always produce outputs in these formats when relevant:

- source summary
- project thesis
- investor narrative
- slide outline
- screen copy
- speaker notes
- FAQ
- objection bank
- approved copy bank
- Canva-ready copy
- GitHub-ready Markdown
