# DNA Change Review - Premium Impact Layer

Status: Working
Date: 2026-04-25
Scope: PRIME / King Tamar / ex-el Brand Presentation OS
Source: Visual reverse-engineering feedback from main presentation chat

## Decision

DNA status: DNA refinement + DNA extension

The core DNA does not change.

The new output confirms the existing direction but exposes a critical execution gap: the system was interpreting premium, institutional and clean as too soft, too polite and too visually restrained.

A new execution layer must be added:

Premium Impact / Authority with Impact

## What stays the same

The following remains unchanged:

1. PRIME is an institutional-premium investment decision system, not a generic real estate brand.
2. King Tamar remains an urban premium position, not only a residential tower.
3. The core narrative remains:
   City -> tourism -> urban development -> address -> King David benchmark -> product -> numbers -> trust -> action
4. King David remains a benchmark, not an enemy.
5. The visual modes remain:
   Authority Dark, Strategic Light Board, Premium Photo Narrative.
6. The core color system remains:
   PRIME Navy, Deep Blue, CTA Blue, White, Cloud, Mist Gray, Graphite, Steel Gray, Champagne Sand.
7. The 70/20/10 color ratio remains.
8. Heebo remains the primary font.
9. The Card System remains the core thinking unit.
10. Circular language remains mandatory.

## What changed

The system now requires a stronger leadership layer in every important slide.

The issue is not that the visual DNA was wrong. The issue is that the output was too polite.

New required layer:

Premium Impact = clean institutional design with stronger typographic leadership, stronger contrast, sharper hierarchy, active focal point and functional circular motifs.

## New mandatory rules

### 1. Typography must lead

Titles must be 20-30 percent stronger on key slides.

Use:
- Heebo Bold / ExtraBold
- short decision headlines
- strong top hierarchy
- one dominant idea

Avoid:
- descriptive titles
- polite business titles
- long soft headlines

### 2. Every slide needs one dominant focal point

At least one of the following must lead:
- large headline
- large KPI
- major image
- active card
- highlighted King Tamar column
- trust seal
- decision capsule

Do not let all elements sit at the same visual volume.

### 3. Cards must feel like premium system components

A PRIME card is not a rectangle.

Required qualities:
- 18-28px rounded corners
- soft shadow
- generous internal spacing
- short title
- controlled text
- small badge / icon / state marker
- clear difference between regular card and leading card
- optional top rule or accent line

### 4. Circular elements must have a role

No decorative circles.

Every circle must act as one of the following:
- Trust Ring
- Laurel KPI
- Circular Seal
- Step Marker
- Decision Marker
- Achievement Marker
- Benchmark Ring
- Location / Product / Timing node

### 5. King Tamar is the active side

In benchmark slides:
- King David = benchmark, market proof, known reference
- King Tamar = active opportunity, new product, updated positioning, review candidate

Avoid VS language.
Use benchmark logic.

### 6. More contrast, not more decoration

Impact must come from:
- large typography
- dark/light contrast
- one active blue point
- strong spacing
- clear hierarchy
- one leading component

Not from:
- shiny gold
- heavy gradients
- clutter
- decorative overload

### 7. Private Banking Impact must appear every 2-3 slides

Add at least one:
- KPI Board
- Trust Badge
- Comparison Board
- Decision Card
- Process Line
- Founder Authority Block
- Risk Framing Note
- Investment Logic Capsule

Updated definition:
Institutional Premium + Urban Prestige + Heritage Story + Strategic Light Board + Premium Impact

Short expression:
Quiet authority with visible power.
