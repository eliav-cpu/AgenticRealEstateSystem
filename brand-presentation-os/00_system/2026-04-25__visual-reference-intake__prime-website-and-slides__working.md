## Global visual insight

The strongest references are not just attractive screens.

They work because they behave like a system:

- strong typography
- cards as product modules
- leadership portraits as trust anchors
- laurels and seals as authority devices
- dark KPI boards for institutional proof
- mobile-friendly stacked card rhythm
- process timelines with numbered decision points
- path/track cards as structured choice
- photo + proof combinations
- one big thought per section

The key lesson:

PRIME design should not chase decoration. It should convert every piece of content into a decision module.

## Reference 01 - Route cards: SMART / COMPASS / INFINITY

### What appears

Three route cards with a large headline, card top accent, plan names, short explanation, price/entry badges and structured feature rows.

### What works

- The user chooses a path, not a generic package
- Cards create a product architecture
- Each route has a clear identity
- Minimal color accents create hierarchy
- The slide/site section feels like a system of choice

### What to take into DNA

Create a formal Track Card system for:

- investment routes
- payment paths
- service levels
- investor profiles
- product packages

### Required rules

- Each card must have a top color rule
- Each card must have a short route name
- Each card must include 3-5 feature lines max
- The leading / recommended path must have visible active state
- Do not overload track cards with paragraphs

### Use in King Tamar

Use for payment tracks, investor suitability, or post-story simulation paths.

## Visual rules extracted from references

1. Cards must be structured like product modules, not information boxes.
2. Titles must lead the section and create a decision.
3. Laurels are authority devices, not decoration.
4. Dark Navy sections should create forceful rhythm every few sections.
5. Leadership imagery must be large and confident.
6. Mobile stack logic is useful for vertical/WhatsApp presentations.
7. Process must be visible through steps, numbers and lines.
8. Route cards are one of PRIME's strongest reusable assets.
9. Map and geography should become strategic focus, not background illustration.
10. Project cards should classify, not just display.
