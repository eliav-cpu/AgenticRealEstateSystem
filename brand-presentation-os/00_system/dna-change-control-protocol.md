# PRIME / King Tamar - DNA Change Control Protocol

Status: Working
Owner: PRIME Invest
Purpose: Review whether new visual research or reverse-engineering output changes the existing Brand Presentation DNA

## Core rule

New visual findings do not automatically change the DNA.

Every new insight must be classified as one of the following:

1. Confirms existing DNA
2. Refines existing DNA
3. Adds a new component
4. Creates a conflict
5. Replaces an existing rule
6. Requires source or visual proof before adoption

## What can change the DNA

A new output can change the DNA only if it provides one of these:

- stronger visual system than the current one
- repeated pattern found across multiple reference decks
- clear correction to current color, spacing, grid or typography rules
- better definition of circular trust language
- better card system logic
- better slide master logic
- better rhythm across decks
- stronger Figma / PPT / Canva implementation rules

## What cannot change the DNA

Do not change the DNA because of:

- one attractive slide only
- one random visual reference
- generic design advice
- new color idea without brand fit
- more decorative style
- Canva-like template suggestion
- language-only improvement
- content correction that does not affect visual system

## Update rule

If the output creates a real DNA change, update the relevant file only after writing a short change note:

- what changed
- why it changed
- which source triggered the change
- which files were updated
- whether this affects King Tamar only or all PRIME projects

## Final review output format

When reviewing new output, return:

1. DNA change status
2. What stayed the same
3. What changed
4. What is only a refinement
5. What conflicts with current DNA
6. Files that need updating
7. Recommended next action
