## File status

Use one of the following statuses in every important file:

- Draft
- Working
- Review
- Approved
- Client Ready
- Archive

## Source discipline

Each project file should clearly separate:

- Verified information
- Project materials
- Working assumptions
- Missing data
- Client-facing approved copy

## Naming convention

Recommended format:

`YYYY-MM-DD__project-or-topic__document-type__status.md`

Examples:

- `2026-04-25__king-tamar__project-brief__working.md`
- `2026-04-25__prime-brand__language-guide__approved.md`

## Presentation rules

- One primary idea per slide
- Maximum 3-5 bullets per slide
- Large headline before supporting text
- Use cards, boards and structured layouts
- Avoid generic real estate brochure style
- Use calm, precise and premium language

## Governance rules

- Do not turn assumptions into facts
- Do not overstate certainty
- Do not use unsupported numbers
- Keep financial language careful and reviewable
- Keep legal and tax wording clearly marked for review
