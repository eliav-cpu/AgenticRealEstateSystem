# King David Benchmark Board - Master Slide Spec

Status: Working
Owner: PRIME Invest
Project: King Tamar
Use case: First approved master proof slide before full deck production

## Purpose

This slide is the first required master proof slide for the PRIME / King Tamar visual system.

It should prove that the system can create a slide that is:

- institutional
- premium
- analytical
- visually powerful
- investor-decision oriented
- not a generic real estate comparison
- not a Canva-style layout

## Core objective

Within 10 seconds, the investor should understand:

King David proves that this urban axis can carry premium value.
King Tamar introduces a new, updated entry point into the same urban logic.

This is not a battle slide.
This is a benchmark slide.

## Strategic message

King David is the benchmark.
King Tamar is the active opportunity for structured review.

King David should support the story.
King Tamar should lead the decision.

King David מוכיח שהציר יודע לשאת פרימיום

## Visual mode

Strategic Light Board + Premium Impact

Required feel:

Quiet authority with visible power

## Layout structure

Recommended structure:

1. Top right: large decision headline
2. Under headline: short explanatory subtitle
3. Center: Comparison Board
4. Left column: King David - Established Benchmark
5. Right column: King Tamar - Active Opportunity
6. Middle / side axis: comparison parameters
7. Bottom: Champagne Sand Bottom Insight Bar
8. Small footer: source / review note

## Visual hierarchy

1. Main headline
2. Active King Tamar column
3. Bottom Insight Bar
4. Comparison rows
5. Source note

If all objects have the same weight, the slide fails.

## Design rules

### Background

Use:

- Cloud #FAFAFB
- Mist Gray #F3F4F6
- White #FFFFFF

### Typography

Font:

Heebo

Recommended sizes:

- H1: 52-64 pt, ExtraBold
- Subtitle: 24-30 pt, Medium
- Column headings: 28-34 pt, Bold
- Table content: 20-24 pt, Medium
- Bottom insight: 24-28 pt, Bold
- Footnote: 9-12 pt, Regular

### Colors

- PRIME Navy #0F1E3A for main headline
- Deep Blue #2F63C8 for active King Tamar border / accent
- CTA Blue #4D8DF7 only for one active badge if needed
- Champagne Sand #D6C7A1 for bottom insight bar or thin premium accent
- Graphite #111827 for main text
- Steel Gray #6B7280 for secondary text / note

### Active King Tamar column

King Tamar must be visually active.

Allowed treatments:

- subtle light blue fill
- Deep Blue thin border
- small active badge
- slightly deeper shadow
- stronger heading weight

### King David column

King David must remain premium and respected.

Allowed treatments:

- white card
- thin neutral border
- softer shadow
- no negative visual treatment

## Circular element rule

Use one functional circular element only.

Allowed options:

- Benchmark Ring
- Circular Seal
- Active Review Badge
- Decision Marker

Suggested badge text:

לבחינה פעילה

or:

Benchmark Logic

Do not use decorative circles.

## Do not use

- VS language
- aggressive comparison
- shiny gold
- raw Excel table
- too many icons
- long paragraphs
- unverified return language
- absolute claims
- decorative circles
- generic Canva layout
