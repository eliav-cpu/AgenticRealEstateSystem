## Objective

Create one master proof slide that proves the PRIME / King Tamar visual DNA before producing the full presentation.

The slide should demonstrate:

- institutional premium look
- urban prestige
- heritage story
- strategic light board logic
- Premium Impact
- circular trust language
- card system
- large Heebo typography
- RTL Hebrew layout
- one dominant focal point

## Recommended first proof slide

### Slide type

King David Benchmark Board

### Why this slide first

This slide is the hardest and most important because it combines:

- benchmark logic
- strategic comparison
- premium design
- investor decision framing
- King Tamar positioning
- controlled language
- circular trust language
- active opportunity hierarchy

If this slide works, the rest of the deck can scale from it.

## Slide title direction

Preferred headline:

King David כ־Benchmark ל־King Tamar

Alternative stronger headline:

ה־Benchmark שמחדד את ההזדמנות

Preferred subtitle:

נקודת ייחוס מוכרת שמאפשרת לבחון כתובת חדשה, מוצר חדש ומסגרת החלטה ברורה

## Visual structure

Use Strategic Light Board mode with Premium Impact.

Recommended layout:

- top right: large decision headline, Heebo Bold / ExtraBold
- top left: small PRIME / King Tamar label
- center: comparison board with 2 columns
- right column highlighted for King Tamar
- middle connector: Benchmark Logic / נקודת ייחוס, not VS
- bottom: strong insight card / framing note
- optional circular seal: Benchmark Logic
- optional rings: Location / Product / Timing / Trust
- footer: source status and review note

## Dominant focal point

The slide must have one clear lead object.

Preferred focal point:

King Tamar active opportunity column.

Execution:

- slightly stronger card depth
- Deep Blue thin border or active top rule
- small circular active badge
- stronger headline weight
- clearer visual depth than King David

King David remains respected and premium, but visually quieter.

## Comparison columns

### King Tamar

Use as the active opportunity.

Possible labels:

- PRIME process wrapper

## Copy rules

Do not attack King David.

King David is not an enemy.
King David is a reference point.
King David proves the category.
King Tamar becomes the active review case.

Avoid:

- better than King David
- replaces King David
- no competition
- guaranteed upside
- obvious winner
- VS language

Use:

- benchmark
- reference point
- comparison logic
- product generation
- location context
- investor review
- active opportunity
- category proof

## Visual requirements

- clean light background
- Navy / Graphite hierarchy
- Deep Blue active highlight
- Champagne thin accents only
- no heavy gold
- no raw table look
- use comparison cards, not Excel table
- large title
- strong whitespace
- one dominant focal point
- functional circular trust motif
- King Tamar active column
- bottom insight line

## Required circular logic

Every circular element must have a role.

Use circles only as:

- Benchmark Ring
- Trust Ring
- Circular Seal
- Location / Product / Timing node
- Decision Marker
- Laurel KPI badge

Do not use circles as background decoration only.
