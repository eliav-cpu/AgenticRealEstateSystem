# King Tamar - Slide Master Brief

Status: Working
Owner: PRIME Invest
Project: King Tamar
Use case: First visual proof slide before building a full deck

## Objective

Create one master proof slide that proves the PRIME / King Tamar visual DNA before producing the full presentation.

The slide should demonstrate:

- institutional premium look
- urban prestige
- heritage story
- strategic light board logic
- circular trust language
- card system
- large Heebo typography
- RTL Hebrew layout

## Recommended first proof slide

### Slide type

King David Comparison Board

### Why this slide first

This slide is the hardest and most important because it combines:

- benchmark logic
- strategic comparison
- premium design
- investor decision framing
- King Tamar positioning
- controlled language

If this slide works, the rest of the deck can scale from it.

## Slide title direction

Preferred headline:

King David כ־Benchmark

Preferred subtitle:

איך בוחנים את King Tamar דרך ציר מוכר, מוצר חדש ומסגרת החלטה ברורה

## Visual structure

Use Strategic Light Board mode.

Recommended layout:

- top right: large decision headline
- top left: small PRIME / King Tamar label
- center: comparison board with 2 columns
- right column highlighted for King Tamar
- bottom: insight card / framing note
- optional circular seal: Benchmark Logic
- footer: source status and review note

## Comparison columns

### King David

Use as benchmark only.

Possible labels:

- established benchmark
- known luxury reference
- mature asset category
- market awareness

### King Tamar

Use as the active opportunity.

Possible labels:

- new premium urban product
- updated architecture and amenities
- flexible investor review path
- PRIME process wrapper

## Copy rules

Do not attack King David.

King David is not an enemy.
King David is a reference point.

Avoid:

- better than King David
- replaces King David
- no competition
- guaranteed upside
- obvious winner

Use:

- benchmark
- reference point
- comparison logic
- product generation
- location context
- investor review

## Visual requirements

- clean light background
- Navy / Graphite hierarchy
- Deep Blue highlights
- Champagne thin accents
- no heavy gold
- no raw table look
- use comparison cards, not Excel table
- large title
- strong whitespace
- subtle circular trust motif

## Success criteria

The slide is approved only if it feels:

- PRIME
- institutional
- premium
- analytical
- visually memorable
- not generic
- not Canva-like
- not a real estate brochure
