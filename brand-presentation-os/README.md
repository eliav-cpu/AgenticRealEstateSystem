## Purpose

This folder is the working system for PRIME Invest brand language, presentation structure, project documentation and reusable content templates.

## Core principle

A PRIME presentation is not a generic deck. It is a structured decision journey for the client.

## Main folders

- `00_system` - rules and governance
- `01_brand` - brand and language guide
- `02_presentations` - slide logic and deck templates
- `03_projects` - project folders
- `04_prompts` - reusable prompts
- `05_message-library` - approved messages
- `06_playbooks` - repeatable workflows

## Working rules

- One clear message per slide
- Clear source status for every project
- Calm, professional and premium language
- No unsupported claims
- No aggressive sales language
- Reuse approved templates before creating new material
