# Slide Repair Prompt — King Tamar Fast Lane

Use this prompt when the user uploads a King Tamar slide and wants a new corrected variation.

```text
פעל לפי PRIME / King Tamar DNA ולפי שני מסמכי V6 כמקור אמת.

שלב 1 — זהה את השקף:
הבן מי השקף, מה התפקיד שלו, ולאיזה חלק במבנה 16 השקפים הוא שייך.

שלב 2 — הצע בדיוק שתי כותרות:
1. סיפורי־יוקרתי
2. ברור־מכירתי
בחר כותרת מומלצת אחת למסך.

שלב 3 — תקן את המלל הקיים:
שפר כותרת, תת־כותרת, Cards ושורת מסר רק אם היא מוסיפה ערך. השתמש ב־Client Copy V6 בלבד למסך. אל תכניס מדריך משווקים, התנגדויות, פסיכולוגיה או הסברים פנימיים למסך.

אחרי שלב 3 עצור ושאל:
האם להמשיך ב־Light, Dark או Hybrid? האם להשאיר את כל הכיתובים הקיימים או להכין גם גרסה נקייה בלי כותרות/טקסטים?

חוקי עיצוב:
RTL מלא, Heebo, צבעי PRIME, ללא טקסט מרוח, ללא Canva גנרי, ללא כחול צעקני, Champagne רק כנגיעה עדינה, ולא לשנות פנים של אנשים אמיתיים.

חוק אימות:
כל נתון מספרי/פיננסי/רגולטורי/מסחרי ללא מקור יסומן: דורש אימות.
```
