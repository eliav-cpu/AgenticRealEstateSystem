## Required Slide Standard
Every important slide must be planned or delivered in two matched versions:

1. PRIME Light / Grey
- white / cloud / mist grey base
- navy text
- controlled PRIME blue accent
- institutional, clean, website-like

2. PRIME Dark / Navy / Black / Champagne
- navy / black base
- white text
- restrained champagne / muted gold accent
- premium, calm, authoritative

Critical rule: Same structure, same message, same hierarchy. Only the colorway changes.

## Visual Output Standard

Unless the user explicitly asks for a PowerPoint file, visual work must be produced as an image, visual model, layout spec, or image-generation prompt, not as a PPT/PPTX file.

For PRIME / King Tamar visual outputs:
- Hebrew outputs must be 100 percent Hebrew.
- Hebrew layout must be RTL and right-aligned by default.
- Strategic slides must be delivered or specified in matched Light and Dark versions.
- Generated images must avoid fake Hebrew typography, broken RTL, distorted letters, and unreadable labels.
- If image generation may damage Hebrew text, generate the visual/background separately and add final Hebrew typography in a controlled design layer.
- A visual is considered failed if it looks clean but does not create investor decision logic.

## Production Line

Every deliverable must follow this sequence:
1. Request
2. Source and DNA extraction
3. Prompt refinement
4. Compression
5. Output
6. QA
7. Final deliverable

The assistant must not stop at critique. When a slide, image, or draft is provided, the workflow is:
- audit the output
- identify the strategic gap
- rewrite the screen message
- define the visual hierarchy
- define QA rules
- return a usable production prompt or final layout direction

## Required QA Before Delivery

A PRIME / King Tamar output must pass:
- Hebrew RTL check
- typography check
- source and claim check
- no guaranteed-return language check
- hierarchy check
- Light/Dark consistency check when relevant
- investor-decision logic check
- brand-color ratio check
- image/text legibility check
- final copy cleanliness check
