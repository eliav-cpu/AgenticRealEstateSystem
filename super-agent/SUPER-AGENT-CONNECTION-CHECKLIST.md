# PRIME / King Tamar Super Agent Connection Checklist

## Purpose
This checklist defines what must be connected, structured and controlled in order to turn the assistant into a production-grade Super Agent for PRIME / King Tamar.

The goal is not more tools.
The goal is one operating system that can handle:
- slides
- investor decks
- banners
- Canva assets
- Figma masters
- Hebrew RTL QA
- source verification
- financial claim control
- CRM and sales flow
- automation
- reusable templates

## Core Principle
The user should not operate the system.
The system should operate for the user.

## Definition Of Ready
The Super Agent is ready when it can:
- receive a slide or banner
- identify the asset type
- preserve the correct style
- fix copy and hierarchy
- protect Hebrew RTL
- mark claims requiring verification
- choose Canva / Figma / Image workflow
- produce full version and clean version instructions
- store outputs in the correct system layer

## Definition Of Done
A client-facing output is done only when:
- Hebrew is clean and RTL
- typography is readable
- no unsupported numbers are invented
- risky commercial language is removed
- PRIME DNA is applied
- full and clean versions exist where relevant
- source status is known
- final asset is archived
