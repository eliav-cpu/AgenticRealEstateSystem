# 03 - Figma Design System Spec

## Purpose
Figma is the master design layer for PRIME visual systems.

Use it for:
- slide masters
- card systems
- Light and Dark variants
- benchmark boards
- campaign frames
- clean templates

## Required Structure

```text
01_Cover_Masters
02_Strategic_Light_Boards
03_Authority_Dark_Boards
04_Card_System
05_Benchmark_Boards
06_Banner_Frames
07_Clean_Templates
```

## Typography

Use Heebo for Hebrew. Hebrew must be live text, right aligned and readable.

## Master Frames

```text
16:9 1920 x 1080
4:5 1080 x 1350
9:16 1080 x 1920
1:1 1080 x 1080
```

## Components

- KPI Card
- Trust Card
- Decision Card
- Comparison Card
- Process Card
- CTA Button
- Bottom Message Bar

## QA

Before export, check:
- readable in 3 seconds
- clean RTL
- sharp typography
- matched Light and Dark versions
- controlled colors
- enough whitespace
- no overload

## Rule
Figma is where the brand becomes a reusable visual system.
