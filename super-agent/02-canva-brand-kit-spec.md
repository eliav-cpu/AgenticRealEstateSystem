# 02 - Canva Brand Kit Spec

## Purpose
Canva is the fast execution layer for banners, social assets, campaign creatives and editable Hebrew visuals.

The Brand Kit must make sure every asset stays inside PRIME / King Tamar DNA.

## Core Rule
Canva is for final editable Hebrew typography and campaign execution.

## Required Brand Kit Assets

### Logos
Add:
- PRIME logo
- PRIME Invest logo
- PRIME white logo
- PRIME navy logo
- project-specific King Tamar lockup if available
- seal / stamp variations

### Colors

- Heebo

Fallback:
- Assistant

Do not mix too many font families.

## Canva Execution Rules

### For Hebrew
- all Hebrew live text
- right aligned
- large enough for mobile
- no flattened generated Hebrew where possible

### For Logo
- logo should support the offer, not dominate it
- bottom placement preferred for banners unless otherwise designed

### For Seal
- seal may be diagonal
- subtle, premium and controlled
- if phrase like השקעה בטוחה is used, treat as brand motif and avoid presenting it as a factual guarantee

### For CTA
Recommended CTA language:
- בדוק התאמה להשקעה
- קבע שיחת התאמה
- בנה סימולציה אישית
- בדיקת זמינות יחידות
- שריין מקום במפגש

## Canva QA
Before export:
- mobile readability pass
- Hebrew RTL pass
- no risky guarantee language
- claim verification pass
- logo size controlled
- CTA visible
- clean version created

## Assistant Behavior
When asked for Canva output, the assistant should prepare:
- exact copy
- frame size
- design hierarchy
- object placement
- brand colors
- full version plan
- clean version plan
- QA checklist

## Short Operating Rule

```text
Canva executes fast, but Hebrew and brand control are non-negotiable.
```
